# Performance review

Foundation decisions: derivative URLs rather than originals in feeds, aspect-ratio dimensions stored before render, Next Image and Expo Image, pagination-ready queries, pgvector HNSW index, search tsvector index, and mobile image transitions.

Release gates: measure cold start, first content, feed frame rate, image memory, search p95, signed-upload success, verification latency, and crash-free sessions. Add CDN transformations, BlurHash generation, resumable video upload, queue backpressure, and scroll-position restoration during Phase 2–3.
