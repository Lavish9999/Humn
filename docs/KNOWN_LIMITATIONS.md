# Known limitations

This repository is a tested-for-structure foundation, not a falsely declared finished public release. External credentials and local infrastructure are required before integration testing. No production claim should be made until CI, Supabase migration tests, real OAuth sandbox tests, signed upload device tests, and store purchase tests pass.

Current intentionally incomplete areas: full onboarding screens; visual-search embeddings; complete Proof Story editor; external media-analysis adapters; appeals UI; comments/reactions; push delivery; RevenueCat/Stripe entitlement webhooks; Creator Studio analytics; local discovery; native marketplace; public legal review.
