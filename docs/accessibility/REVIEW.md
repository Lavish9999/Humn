# Accessibility review

Target: WCAG 2.2 AA where applicable.

Implemented in the foundation: semantic headings and landmarks on web, form labels, status regions, alt-text fields, platform font scaling, high-contrast tokens, reduced-motion CSS, and non-color status labels. Mobile uses native Text/Input/Pressable controls and accessibility labels for Work media.

Required before release: VoiceOver/TalkBack screen-by-screen audit, keyboard-only web audit, 200% zoom review, Dynamic Type extremes, captions workflow, focus restoration for sheets, accessible masonry reading order, and paywall/moderation-console audits.
